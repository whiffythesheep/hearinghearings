# Hearing Hearings

Plain-language summaries of NYC Council hearings, published at [hearinghearings.nyc](https://hearinghearings.nyc).

Each summary pairs a structured overview with the full cleaned transcript, linked back to the original recording (YouTube or the Council's Viebit stream) and the Legistar meeting page. Every timestamp in the transcript is a deep link into the video at that moment.

A personal project.
