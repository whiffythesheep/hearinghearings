# cryptography is a transitive dependency (pdfplumber -> pdfminer.six needs it to
# decrypt encrypted PDFs). Declared here only to hold a security floor: 50.0.0
# clears all seven open advisories, the newest being GHSA-g6cj-pr64-35w5 (PKCS#7
# Bleichenbacher oracle). This file must never name a vulnerable version --
# Dependabot parses it and does NOT evaluate environment markers, so a marker-
# guarded old pin still raises alerts. The Windows ARM64 exception (no wheels
# published after 46.0.3, no Rust toolchain to build from source) therefore lives
# in constraints-win-arm64.txt, which Dependabot does not read as a manifest.
# The marker below makes this line inert on ARM64 so that constraint can apply
# without conflicting. See CLAUDE.md "Windows ARM64 install".
cryptography>=50.0.0; platform_machine != "ARM64" or sys_platform != "win32"
