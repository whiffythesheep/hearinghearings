Res 0534-2026

Resolution to set property tax class shares for 2027

Law or adopted · Sponsor: Linda Lee · View on Legistar ↗

In brief

This resolution certifies to the State Board of Real Property Tax Services the base percentage, current percentage and current base proportion of each of the City's four property tax classes for fiscal year 2027, as required by state law. It caps the increase in Class 1's share at 5% and shifts the excess proportion to Classes 3 and 4, while Class 2 increases 0.4% and Classes 3 and 4 decrease. These figures set the baseline used to determine how much each property class will pay toward the city's tax levy.

Official title

RESOLUTION COMPUTING AND CERTIFYING BASE PERCENTAGE, CURRENT PERCENTAGE AND CURRENT BASE PROPORTION OF EACH CLASS OF REAL PROPERTY FOR FISCAL 2027 TO THE STATE BOARD OF REAL PROPERTY TAX SERVICES PURSUANT TO SECTION 1803-a OF THE REAL PROPERTY TAX LAW
