Introduction

Int 0421-2026

Law to let new cellar apartments be rented out

Law or adopted · Sponsors: Pierina Ana Sanchez, Farah N. Louis, Mercedes Narcisse, Shaun Abreu, Jennifer Gutiérrez · View on Legistar ↗

In brief

This bill would allow cellar ancillary dwelling units built as part of new construction in one- and two-family homes to be rented out, matching the existing rules for such units created in older homes. It amends the city's housing maintenance code and would take effect immediately upon enactment.
